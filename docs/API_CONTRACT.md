## 5. QUY TẮC BẢO MẬT VÀ XÁC THỰC CONTRACT

- **Session Authentication**:
  - Mọi request hướng tới các endpoint nghiệp vụ game (`/xhrpg_*.php` ngoại trừ public assets và google auth mock) bắt buộc phải truyền `line_uid` và `session_token`.
  - Server xác thực session qua câu lệnh `SELECT * FROM users WHERE line_uid = ? AND session_token = ?`.
  - Nếu token không khớp hoặc user đã logout, server từ chối với status **HTTP 401 Unauthorized** và payload `{ ok: false, error: 'Unauthorized: invalid session token' }`.
- **Zero Sensitive Data Logging**:
  - Toàn bộ dữ liệu nhạy cảm (`password`, `session_token`, `password_hash`, `payment_token`, `card_number`, URL query keys) bắt buộc phải bị redact thành `[REDACTED]` ở cả tầng Express HTTP Logging lẫn Database Query Logging theo đúng tiêu chuẩn bảo mật TASK-040.
